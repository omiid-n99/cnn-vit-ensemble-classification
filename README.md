# CNN, ViT and Ensemble Models for Image Classification

Deep-learning university project comparing convolutional neural network
approaches, Vision Transformers (ViT), and ensemble methods for image
classification.

## Project Objectives

- Develop and evaluate a proposed image-classification approach.
- Compare it with a CNN baseline.
- Compare it with a Vision Transformer.
- Evaluate ensemble methods combining multiple models.
- Perform experiments under a consistent evaluation methodology.
- Ensure experiments are reproducible and executable on Google Colab.

## Project Structure

- `src/` - Core implementation
- `src/models/` - Model architectures
- `configs/` - Experiment configurations
- `notebooks/` - Google Colab experiment notebook
- `results/` - Metrics, figures, and tables
- `tests/` - Basic tests and sanity checks
